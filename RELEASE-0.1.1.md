# File 15 corrective release candidate 0.1.1

This release candidate corrects the defects identified during the formal audit of the preserved 0.1.0 baseline.

## Corrected

- Dedicated Radar post and taxonomy capabilities.
- Publication enforcement across Classic Editor, REST, imports, scheduled publishing, WP-CLI, and programmatic updates.
- Mandatory source, approved license, review date, confirmations, authorized approval, and audit records.
- Safe page ownership and slug-collision behavior.
- File 20 shell compatibility without duplicate global navigation.
- Structured-field keyword search.
- Shortcode-aware no-cache and noindex protection for private Saved Studies.
- User-deletion cleanup, throttling, and per-user limits for Saved Studies.
- Accessibility, color contrast, remedy selector, and landmark corrections.
- Schema-versioned upgrades, corrected checksums, and automated regression gates.

## Release gates still open

WordPress fresh-install, upgrade, role-matrix, REST, scheduled-publication, dependency, responsive, accessibility, rollback, and Hostinger staging acceptance remain required before merge or production deployment.
