The first 25 percent of a structured, referenced, American English Radar research system.

== Description ==

This modular foundation replaces the Radar placeholder with:

* Public symptom and rubric search without registration.
* Filters for category, body region, location, sensation, aggravation, amelioration, concomitants, causation, time, temperature, and remedy name.
* Referenced Radar entries with source, license, and review-date controls.
* Founder or administrator direct publishing with all other submissions held for review.
* Public comparison of up to three published Encyclopedia remedy entries.
* Private anonymous Saved Studies for verified doctors.
* WordPress privacy export and erasure support for private studies.
* DefinedTerm structured data for public Radar entries.
* Responsive American English design using the approved bright orange color.

Radar is an educational research tool. It does not diagnose disease, select treatment, recommend potency or dosage, promise a cure, or replace qualified medical and emergency care.

== Installation ==

1. Keep Files 01, 03, 06, 07, and 09 active for complete navigation, Encyclopedia remedy comparison, doctor verification, and saved-study access.
2. Open WordPress Admin > Plugins > Add New > Upload Plugin.
3. Upload this ZIP and select Install Now.
4. Activate Radar Symptom and Remedy Analysis Foundation.
5. Open Radar Entries > Add Radar Entry to add original, licensed, or public-domain research material.
6. Supply both Reference Source and Source License before publishing.
7. Clear the Hostinger and browser caches, then open the Radar button publicly.

== Copyright and Publication Rules ==

Do not copy copyrighted repertory text. Publish only material that is original, properly licensed, or in the public domain. Every published Radar entry requires a recorded reference source and source license.

== Privacy ==

Saved Studies accept an anonymous title, up to three public Radar entry identifiers, and private research notes. Patient names, phone numbers, addresses, record numbers, and other identifying information are prohibited. The saved-studies page is private, uncached, and noindex.

== Not Included in This Release ==

* Automated diagnosis or prescribing.
* Potency or dosage recommendations.
* Autonomous AI treatment decisions.
* Complete advanced repertorization.
* Copyrighted repertory databases.
* Patient medical records.
* Doctor-to-patient prescription sending.
