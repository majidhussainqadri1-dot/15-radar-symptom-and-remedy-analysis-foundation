=== Radar Symptom and Remedy Analysis Foundation ===
Requires at least: 6.0
Requires PHP: 7.4
Stable tag: 0.1.1
License: GPLv2 or later

The first 25 percent of a structured, referenced, American English Radar research system.

== Description ==

This modular foundation provides:

* Public symptom and rubric search without registration.
* Keyword search across titles, content, and structured Radar fields.
* Filters for category, body region, location, sensation, aggravation, amelioration, concomitants, causation, time, temperature, and remedy name.
* Dedicated Radar capabilities for administrators, the Founder, reviewers, and verified-doctor submissions.
* Context-independent publication enforcement for Classic Editor, REST, imports, scheduled publishing, WP-CLI, and programmatic updates.
* Mandatory reference source, approved source license, review date, American English confirmation, medical-safety confirmation, and authorized approval.
* Public comparison of up to three published Encyclopedia remedy entries through one accessible multi-select control.
* Private anonymous Saved Studies for verified doctors.
* No-cache and noindex protection wherever the Saved Studies shortcode is rendered.
* WordPress privacy export and erasure support, including automatic study deletion when the owning user is deleted.
* Status and metadata audit records for Radar entries.
* DefinedTerm structured data for public Radar entries.
* Responsive American English design using the approved bright orange color with accessible dark button text.
* Compatibility with the File 20 Unified Application Shell without rendering a duplicate global navigation bar.

Radar is an educational research tool. It does not diagnose disease, select treatment, recommend potency or dosage, promise a cure, or replace qualified medical and emergency care.

== Installation ==

1. Keep Files 01, 03, 06, 07, 09, and 20 active for complete shell navigation, Encyclopedia remedy comparison, doctor verification, and saved-study access.
2. Open WordPress Admin > Plugins > Add New > Upload Plugin.
3. Upload the ZIP and select Install Now.
4. Activate Radar Symptom and Remedy Analysis Foundation.
5. Open Radar Entries > Add Radar Entry to add original, licensed, or public-domain research material.
6. Supply the Reference Source, an approved Source License, Last Reviewed Date, and both confirmations before requesting publication.
7. Clear the Hostinger and browser caches, then open the Radar page publicly.

== Created Pages ==

* Radar at the plugin-managed Radar page.
* Radar Saved Studies at the plugin-managed private Saved Studies page.

If an existing unowned page already uses the preferred slug, the plugin creates a separate WordPress-unique managed page instead of taking over unrelated content.

== Copyright and Publication Rules ==

Do not copy copyrighted repertory text. Publish only material that is original, properly licensed, or in the public domain. Every public Radar entry requires a recorded reference source, an approved source license, a valid review date, both confirmations, and authorized approval.

== Privacy ==

Saved Studies accept an anonymous title, up to three public Radar entry identifiers, and private research notes. Patient names, phone numbers, addresses, record numbers, and other identifying information are prohibited. Every page containing the Saved Studies shortcode is private, uncached, noindex, noarchive, and nofollow. Saved studies are removed when the owning user account is deleted and are supported by the WordPress personal-data export and erasure tools.

== Not Included in This Release ==

* Automated diagnosis or prescribing.
* Potency or dosage recommendations.
* Autonomous AI treatment decisions.
* Complete advanced repertorization.
* Copyrighted repertory databases.
* Patient medical records.
* Doctor-to-patient prescription sending.
